# Project: PIISC School Backend

## Stack

Node.js, Express, MongoDB (Mongoose), JWT auth (later)

## Structure

src/models, src/controllers, src/routes, src/middleware, src/config

## Rules

- Follow the pattern: model -> controller -> route
- Use async/await with try/catch
- Never hardcode secrets; use process.env
- Do not install new packages without asking me first
- Do not modify files I did not mention
- Keep code simple and commented; I am a learner
- After any change, explain what each file does and why
- Work in small steps and wait for my approval before the next one
